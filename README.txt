STUDY BLOCK TIMER - GITHUB PAGES SETUP

1. Create a new GitHub repository, e.g. study-timer.
2. Upload ALL files from this folder to the repository root:
   - index.html
   - manifest.webmanifest
   - icon-192.png
   - icon-512.png
3. In GitHub: Settings > Pages.
4. Under Build and deployment choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
5. Save. GitHub will provide a URL such as:
   https://YOUR-USERNAME.github.io/study-timer/
6. Open that URL in Safari on iPhone/iPad.
7. Tap Share > Add to Home Screen > Add.

Use the same URL consistently so Safari uses the same saved timer settings and session logs.
